# OmniPulse BI: Next-Gen Interactive Data Analytics & BI Control Center

[![UI Glassmorphic](https://img.shields.io/badge/Design-Glassmorphic%20Obsidian-cyan.svg)]()
[![Chart.js](https://img.shields.io/badge/Charts-Chart.js%20v4-violet.svg)](https://www.chartjs.org/)

**OmniPulse BI** is an ultra-sleek, interactive, state-of-the-art Business Intelligence and Data Analytics Command Center designed for high-performance executive dashboards, predictive forecasting, real-time event streaming, and SQL querying.

---

## 🌟 Key Features

- **Executive Overview Dashboard**:
  - Real-time ARR, Active Users, Conversion Rate, and Query Throughput KPIs with mini-sparklines.
  - Interactive Chart.js velocity stream graph (Revenue vs. Event Volume).
  - Tier Split Doughnut chart with custom center status overlays.
  - Streaming live event transaction feed (updates every 2s).
  - Hardware cluster utilization gauges (CPU, RAM, NVMe I/O, Cache Hit Ratio).

- **Predictive AI Lab**:
  - Time-series Monte Carlo growth simulator with 95% confidence bounds.
  - Dynamic parameter sliders (R&D boost, churn rate, expansion multiplier) with instant recalculation.
  - AI Smart Recommendations with single-click query auto-tuning.

- **Geospatial Telemetry Hub**:
  - Interactive world map nodes (US-East, US-West, EU-Central, APAC, SA-East) with pulsing ping indicators and hover data tooltips.
  - Regional latency, uptime, and traffic breakdown tables.

- **Live SQL Analytics Studio**:
  - Interactive SQL code editor with syntax formatting and query presets.
  - Instant result tables with multi-column text search filtering and CSV export simulation.

- **Telemetry & Anomaly Alerts**:
  - Categorized alert feed (Critical, Warning, Info) with single-click acknowledgment workflow.

- **Dynamic Theme Accent Switcher**:
  - Switch between **Cyber Cyan**, **Electric Violet**, **Matrix Emerald**, and **Solar Amber** themes instantly.
